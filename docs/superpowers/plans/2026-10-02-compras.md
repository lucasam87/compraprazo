# Compras parceladas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Implementar prévia e confirmação segura de compras parceladas usando a RPC transacional existente.

**Architecture:** Schemas validam o formulário; uma Action protegida consulta cliente/configuração e chama apenas `criar_compra`; a tela usa as funções financeiras puras para prévia, sem duplicar regras. A RLS e a RPC permanecem autoridade para crédito e atomicidade.

**Tech Stack:** Next.js App Router, TypeScript, React, Supabase SSR, Zod, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-02-compras-design.md`

## Global Constraints

- Dinheiro permanece em centavos inteiros e parcelas somam exatamente o total.
- Todas as regras financeiras continuam em `src/lib/calculos.ts`.
- Compra + parcelas são criadas atomicamente pela RPC `criar_compra`.
- Cliente bloqueado não compra; exceção só para dono e deve ser auditada.
- Nenhum segredo privilegiado chega ao navegador.

## Review Focus

- Valor com casas decimais ou zero deve ser rejeitado antes da RPC — Task 1.
- Data inválida e quantidade fora de 1–24 devem ser rejeitadas — Task 1.
- Erro da RPC deve virar mensagem neutra — Task 2.
- Exceção não pode ser aceita por atendente — Task 2.
- Prévia exibida deve somar exatamente o valor informado — Task 3.
